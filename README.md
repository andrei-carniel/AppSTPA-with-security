# AppSTPA with security
New version of AppSTPA Tool

# Project Documentation

This work is the result of my Ph.D. research performed on Instituto Tecnológico de Aeronáutica - ITA by Andrei Carniel under the supervision of Prof. Celso Massaki Hirata.

This is a frozen version of AppSTPA, this version encompasses business and security analysis. Below is an overview of the folder structure and their respective contents:

## Folder Structure

- **`other-analyses/`**  
  Contains additional analyses and supporting data that provide insights and complementary information for the project. This version presents an Adaptative Cruise Control as suplementary analyses.

- **`ontologies/`**  
  Includes all ontology-related files and resources, such as models, schemas, and definitions used in the project and manuscript.

- **`source-code/`**  
  The core source code of the project. This folder houses the implementation files, scripts, and any necessary libraries.

- **`App/`**  
  Contains the application-related files (.exe), including the main app interface, configurations, and deployment resources.

This is the  **source code** for the **AppSTPA**. The code is under **GPL license**.
